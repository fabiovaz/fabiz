# Fabiz

Site institucional da Fabiz, feito em [Next.js](https://nextjs.org) com Tailwind CSS v4, exportado como site estático.

## Setup

```bash
pnpm install
```

## Desenvolvimento

```bash
pnpm dev
```

Acesse `http://localhost:3000`.

## Build

```bash
pnpm build
```

Gera o site estático na pasta `out/`.
